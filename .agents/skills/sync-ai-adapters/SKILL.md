# Sync AI Adapters

`.agents/` is the source of truth. Adapter folders (`.claude/`, `.cursor/`, `.github/agents`, ...) are generated.

## Steps

1. Edit the canonical file in `.agents/` first, never the adapter copy.
2. Preview: `node .ai/cli/bin/cli.mjs sync --dry-run`.
3. Apply: `node .ai/cli/bin/cli.mjs sync` (all tools from the installed config) or `--target claude`.
4. Add `--clean` to remove adapter skills that no longer exist in `.agents/skills/`.
5. Verify: `node .ai/cli/bin/cli.mjs sync --check` exits 0.

## Ownership rule

Generated files carry a `Generated by engr-toolbox` header. Sync updates only files with that header. **To own a file and stop sync from touching it, delete the header line.**

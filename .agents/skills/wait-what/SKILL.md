# Wait What

The user did not follow your last message.

1. Find what they were missing: a term, a step you skipped, or context only you had.
2. Re-pitch it in plain language, shortest first. Define any term using `GLOSSARY.md` wording.
3. End with one line: what this means for them or what they should do.

No new information, no lecture. If the confusion came from a fuzzy project term, suggest adding it to `GLOSSARY.md`.

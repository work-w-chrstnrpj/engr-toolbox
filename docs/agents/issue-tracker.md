# Issue Tracker

**Tracker:** local

- Tickets: `tickets/<feature>/NN-<slug>.md`, spec in `tickets/<feature>/spec.md`. Ticket ID: `<feature>/NN`.
- Status: the `**Status:**` line. Blockers: `**Blocked by:**`. History: `## Progress log`.
- Board: `tickets/BOARD.md`, regenerated by `node .ai/cli/bin/cli.mjs status --write`.
